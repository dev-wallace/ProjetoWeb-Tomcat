# Projeto CRUD com Login de Usuário

Este é um projeto desenvolvido em sala de aula como parte das atividades acadêmicas. Trata-se de uma aplicação CRUD (Create, Read, Update, Delete) com funcionalidade de login de usuário, utilizando banco de dados para persistência e JSP para validação.

## Funcionalidades

- **Login de Usuário**: Interface amigável para autenticação com validação no back-end.
- **Cadastro de Usuário**: Tela para registrar novos usuários no sistema.
- **Gerenciamento de Usuários**: Funções CRUD para gerenciar informações de usuários cadastrados.
- **Segurança Básica**: Verificação de credenciais para acesso restrito.

## Tecnologias Utilizadas

### Front-end
- **HTML5**: Estrutura da interface.
- **CSS3**: Estilização da aplicação.
- **Font Awesome**: Ícones.
- **Ionicons**: Ícones para inputs do formulário.

### Back-end
- **Java (JSP)**: Renderização dinâmica e validação de dados do usuário.
- **Banco de Dados**: Persistência de dados (MySQL, PostgreSQL ou outro relacional).
- **Servlets**: Manipulação de requisições e respostas HTTP.

### Ferramentas
- **Eclipse IDE** ou **IntelliJ IDEA**: Ambiente de desenvolvimento.
- **Apache Tomcat**: Servidor para execução da aplicação.
- **Git**: Versionamento de código.

## Estrutura do Projeto

- **/web/paginas**: Contém as páginas JSP como `cadastrar_usuario.jsp` e `validar.jsp`.
- **/css**: Contém o arquivo `style.css` para estilização.
- **/js**: Contém scripts JavaScript.
- **/WEB-INF**: Configurações e arquivos de suporte do projeto.

## Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/dev-wallace/ProjetoWeb-Tomcat
   ```

2. Importe o projeto em sua IDE favorita.

3. Configure o banco de dados:
   - Crie um banco de dados com a estrutura necessária.
   - Atualize as credenciais no arquivo de configuração (como o arquivo de conexão JDBC).

4. Inicie o servidor Apache Tomcat.

5. Acesse a aplicação no navegador em: `http://localhost:8080/seu-projeto`.
